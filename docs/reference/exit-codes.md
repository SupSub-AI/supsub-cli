# 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 成功 |
| `1` | 一般业务错误（后端 4xx，如分组 / 关注点不存在、未订阅、重复订阅） |
| `2` | 未登录 / 鉴权失败 |
| `3` | 套餐已过期 |
| `10` | 网络错误 |
| `11` | 服务端错误 |
| `64` | 参数非法 |

可在脚本中据此判断结果，例如配合 `-o json` 做自动化。

## `64` — 本地参数校验

退出码 `64` 覆盖各命令的本地参数校验，典型场景：

- `--type` 取值不在枚举内
- ID 不是正整数
- `--all` 与 `--unread` 互斥冲突
- `--page-size` 超出 `1`-`100`
- `mark-read` 未给 `--all`，或误传单篇参数（`--content-id`）

::: tip 无副作用
这类错误在发请求**之前**抛出，不会产生任何副作用。
:::

## `1` vs `11` 的分界

分界只看 **HTTP 状态码**：5xx 才是 `11`，其余 4xx 一律 `1`，与错误「像不像业务问题」无关。

因此「分组不存在」（404）退的是 `1` 而非 `11`。
