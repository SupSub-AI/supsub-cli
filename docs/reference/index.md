# 命令参考总览

本章罗列 `supsub` 在终端中**当前已实现、可直接使用**的全部功能：命令、参数、行为与终端层面的约定。

## 全局用法

```
supsub [全局选项] <命令> [子命令] [参数]
```

| 全局选项 | 说明 | 默认 |
|---|---|---|
| `-o, --output <table\|json>` | 输出格式 | `table` |
| `--api-url <url>` | 指定 API 基地址（优先级高于 `SUPSUB_API_URL` 环境变量） | `https://supsub.net` |
| `-V, --version` | 打印版本号 | — |
| `-h, --help` | 打印帮助（每个子命令也支持） | — |

## 信息源类型 `--type`

全 CLI 统一取值 `MP`（公众号）/ `WEBSITE`（网站）/ `X`（推特），**大小写不敏感**。

::: warning 后端只认 `X`
推特类型的值是 `X`，**不是** `TWITTER`。
:::

表格输出里的「类型」列渲染为中文（公众号 / 网站 / 推特）；分组成员还可能出现从网页端加入的**播客** / **通讯**，因此 `group subs --type` 额外接受 `PODCAST` 与 `NEWSLETTER`。

## 命令一览

| 命令组 | 用途 |
|---|---|
| [`auth`](./auth) | 登录、查看状态、登出 |
| [`sub`](./sub) | 订阅源：列出 / 添加 / 取消 / 看文章 / 整源已读 |
| [`focus`](./focus) | 关注点：列出 / 看内容 / 整体已读 / 删除 |
| [`group`](./group) | 订阅分组：增删改查 + 成员进出 |
| [`unread`](./unread) | 订阅源 + 关注点的未读概览 |
| [`search`](./search) | 全站搜索（信息源 + 文章正文） |
| [`deepread`](./deepread) | 精读：对单篇文章做 AI 深度拆解（按次消耗额度） |
| [`mp`](./mp) | 公众号发现（异步搜索 / 取消） |
| [`update` / `skills`](./update) | CLI 自更新与 Agent Skills 同步 |
